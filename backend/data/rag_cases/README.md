# RAG Case Library

This directory is intentionally empty in git. Users should add one folder per
high-quality math modeling case:

```text
case-id/
  problem.pdf        # or problem.md/problem.txt/problem.docx
  paper.pdf          # or paper.md/paper.txt/paper.docx
  data/              # optional provided data
  notes.md           # optional method notes
```

Do not commit user papers, contest attachments, or private data.
